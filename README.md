### 🧠 The Evolution (From Code to Pixel)
I used to see the world through `<div />` tags; now, I design how users **feel** inside those divs. I haven't left coding behind; I've simply shifted my focus from "how it works" to "how it feels."

* **The Former Me:** Used to fight with syntax errors. ⌨️
* **The Current Me:** Dances with negative space and typography. 🎨
